# 得点内訳パーツの拡大→移動演出 設計

## 背景・目的

直前に実装した「場札プレイ時の得点内訳表示・アニメーション」(`docs/superpowers/specs/2026-07-27-shidasu-score-breakdown-design.md`)では、得点内訳(基礎点・パターン・役・護符・コンボ倍率など)を1つずつ内訳行にテキストとして直接追加していくだけで、パーツ自体の登場演出がなかった。実際にブラウザで動作確認した結果、各パーツの発生がもう少し視覚的に強調される方が分かりやすいというフィードバックを受け、以下の改善を行う。

## 変更点

### 1. 内訳行の表示順序を反転する

現在、`PlayArea.svelte`の内訳行は「+合計 内訳テキスト」(合計が左、内訳が右)という順で表示している。これを「内訳テキスト +合計」(内訳が左、合計が右)の順に変更する。

### 2. パーツごとの拡大→移動演出を追加する

各パーツを1つ表示するたびに、以下の2段階のアニメーションを行う:

1. **中央拡大表示**: 画面中央に、通常表示の2倍のサイズでそのパーツのテキスト(`text`、例: `"同スート+50"`)を表示する
2. **内訳行への移動**: 拡大表示の位置から、内訳行(左側、パーツテキストが追加される場所)の座標へ向けて、縮小しながら移動する

移動が完了した瞬間に、そのパーツのテキストが内訳行に確定表示される(それまでは内訳行には追加されない)。

**対象範囲**: パーツの合計数に関わらず、常にこの演出を行う。既存仕様にあった「パーツが1つだけ(基礎点のみ)の地味なプレイは即時表示にスキップする」という例外は廃止し、パーツが1つの場合もこの拡大→移動演出を1回行う。

**タイミング**: 既存の「1パーツあたり280ms」という間隔は維持する。この280msを、中央拡大表示の持続時間と、内訳行への移動時間の合計に充てる(例: 拡大表示150ms + 移動130ms = 280ms。具体的な内訳比率は実装時に調整してよい)。

### 3. 合計加点数の強調アニメーションを追加する

内訳行右側の「+合計」表示は、各パーツの拡大→移動が完了して合計値(仮合計)が更新されるたびに、一瞬拡大してから元のサイズに戻る強調演出を行う。パーツが1つだけの地味なプレイでも、この強調は(合計確定時に)1回発生する。

### 4. 既存の「SCOREへの飛び込みアニメーション」との関係

全パーツの拡大→移動・強調演出が完了した後に発生する、既存の「+合計がSCORE欄へ飛び込む」演出(`docs/superpowers/specs/2026-07-27-shidasu-score-breakdown-design.md`で定義済み)はそのまま変更しない。

## 実装方針

既存の`playingAnimation`(場札カードのチェーンへの移動)・`scoreReveal`(SCOREへの飛び込み)と同じ設計パターンを踏襲する: `position: fixed`のオーバーレイ要素、`getBoundingClientRect`による開始・終了座標の計算、複数フェーズの状態遷移(`$state`+`setTimeout`+`requestAnimationFrame`)。

- 中央拡大表示の開始位置は画面中央の固定座標(`window.innerWidth / 2`, `window.innerHeight / 2`ベース)
- 移動の終了位置は、内訳行のコンテナ要素(`bind:this`で参照)の座標
- 強調アニメーションはCSS transitionによる`transform: scale(...)`の一時的な変化で実現する

## 除外・非対象

- 山札めくり(`applyDrawStock`)経由の得点表示は既存仕様通り対象外で、この拡大→移動演出も適用しない
- SCOREへの飛び込みアニメーション自体の見た目・タイミングは変更しない
