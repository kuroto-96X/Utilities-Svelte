# ヘッダー・フッター スマホ表示最適化 デザイン仕様

## 概要

現状、上部ナビ（サイト名＋カテゴリーボタン横並び）と下部フッター（アイコン＋名前＋bio＋SNSリンク）は、スマホ幅では収まりきらず折り返し・詰まりが発生している。スマホ表示時のみレイアウトを切り替え、画面内に収まるようにする。PC・タブレット幅（現行レイアウトが収まる幅）では現状のレイアウトを維持する。

## 切り替え基準（ブレークポイント）

- JSによる実行時のDOM幅計測は行わない（初期表示のちらつき・SSRとの不整合を避けるため）
- 各カテゴリーボタンの幅を実測してコード内に定数化する（例: `楽曲制作`・`プログラミング`・`画像`・`投資`・`ゲーム` の5個分＋ロゴ部分の基準幅）
- prerender時に、`toolVisibility` を反映した後の「実際に表示されるカテゴリーの組み合わせ」から必要幅を合計し、その値をCSSのブレークポイントとして埋め込む
- `/admin/menu` でのツール表示/非表示切り替え（＝カテゴリーが減る方向のみ）は、既存の「反映には再ビルド・再デプロイが必要」という規約の通り、次回ビルドで自動的にブレークポイントにも反映される
- `site.ts` の `categories` 配列自体を変更した場合（カテゴリー追加・ラベル文言変更）は、実測値の定数がずれるため、再計測して定数を更新する必要がある。この点をCLAUDE.mdに追記する
- カテゴリーが減った場合、必要幅の定数も同時に減るため常に安全側（PC版で収まる幅を早めにスマホ版へ切り替えることはあっても、崩れることはない）

## ヘッダー（スマホ表示時）

### レイアウト

```
[96X's Tools] [現在ページ名（省略表示）]              [☰]
```

- サイト名ロゴ＋現在ページ名＋ハンバーガーアイコンの3要素を1行に収める
- 「現在ページ名＋ハンバーガーアイコン」のエリア全体を1つのタップ対象とし、メニューの開閉をトグルする
- トップページ（`/`）ではページ名部分を表示せず、ハンバーガーアイコンのみ表示する
- 現在ページ名の解決ロジック: `routeId` が `tool.href` と完全一致、または `${tool.href}/` から始まる場合、その `tool` のラベルを使用する（`image-tools` 配下のサブページなど、既存の `isNoIndex` 判定と同じ prefix マッチングを再利用する）
- 該当するツールが見つからない場合（今回のスコープ外のページ等）は、ハンバーガーアイコンのみ表示する

### メニューの中身

- ハンバーガーをタップすると、ヘッダー直下にドロップダウンパネルが開く（画面全体を覆うモーダルにはしない。既存デスクトップ版のカテゴリードロップダウンと同じ「ヘッダー下に浮くパネル」方式を踏襲する）
- パネル内は全カテゴリーをアコーディオン形式で縦に並べる
  - 現在ページが属するカテゴリーは開いた状態で初期表示
  - それ以外のカテゴリーは閉じた状態で初期表示
  - カテゴリー見出しをタップするとそのカテゴリーの開閉をトグルする（複数カテゴリーを同時に開いた状態にできる。排他制御はしない）
- 開いたカテゴリー内には、そのカテゴリーの `visible: true` なツールを一覧表示する（現在ページはティールのドット＋太字でハイライト。既存デスクトップ版ドロップダウンと同じスタイル）
- ツールリンクをタップするとページ遷移し、メニューは自動的に閉じる
- パネル外タップ・Escキーで閉じる（既存の `svelte:window onclick` / `Escape` ハンドリングと同じ仕組みを流用する）

## 画面下部のツール一覧バー（ピル表示）

- スマホ表示時は非表示にする（ヘッダーメニューのアコーディオンと内容が重複するため）
- PC・タブレット幅では現状のまま表示を維持する

## フッター（自己紹介バー）

### スマホ表示時: 2段組

```
[アイコン] [名前]                    [@handle] [BOOTH] [YouTube]
[bio全文（折り返し表示）]
```

- 1行目: アイコン＋名前＋SNSリンク（X/BOOTH/YouTube）
- 2行目: bio全文。truncateせず折り返して全文表示する

### PC・タブレット幅

- 現状の1行レイアウト（アイコン＋名前＋bio(truncate)＋SNSリンク）を維持する

## 対象外（スコープ外）

- カテゴリーボタン自体のラベル文言・カテゴリー構成の変更
- `/admin` 系管理ページのレイアウト最適化（開発者向けのため対象外）
- PC・タブレット幅のデザイン変更
