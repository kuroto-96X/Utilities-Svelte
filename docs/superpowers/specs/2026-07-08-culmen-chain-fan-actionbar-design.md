# Culmen チェーン表示をアクションバーに統合(実カードサイズ重ね表示) 設計

## 0. 背景・目的

直前の再設計(`docs/superpowers/specs/2026-07-08-culmen-chain-display-redesign-design.md`)で、`wave.chain`を山札由来(`chainOrigin`)を区別した縦位置違いの重ね表示にしたが、プレイエリアの一番下(山札ボタン・場札・アイテムバッジの行)とは別に、専用の表示行を新設していた。

今回、この専用行を廃止し、山札ボタンの右にある「場札(foundation)」表示の位置そのものに、チェーン全体(`wave.chain`)を実際のカードと同じ見た目・同じサイズで重ねて表示する形に変更する。`foundation`は常に`chain`の最後の1枚と同じカードのため、単独の場札表示は不要になる(チェーンの一番手前の札がそのまま「現在の場札」を表す)。

## 1. スコープ

- 対象: `src/routes/game/culmen/+page.svelte`のみ(`playArea`スニペット内、アクションバー部分の書き換え)
- 対象外: `src/lib/game/culmen/engine.ts`・`types.ts`・`engine.test.ts`(データモデル・スコア計算は一切変更しない。`chain`/`chainOrigin`は既存のまま利用する)
- 前回追加した「チェーン専用表示行」(現在の実装、`+page.svelte`のアクションバー直前にある独立した重ね表示ブロック)は完全に削除する
- 前回追加した単独の場札(`{@render cardFace(displayWave.foundation, false)}`)表示も削除し、チェーンの重ね表示に統合する

## 2. 表示仕様

### 2.1 カードの見た目・サイズ

チェーンの各カードは、既存の`cardFace`スニペット(`covered: false`固定、ピップ・面札記号・上下両コーナーのランク/スート表示を含むフル表示)をそのまま再利用する。サイズは既存の場札(`w-16`、`aspect-ratio: 2/3`)と同じにする。

### 2.2 横方向の重ね

各カード`chain[i]`(行内でのインデックスを`j`とする。3節参照)は、`left: j * 32px`に絶対配置し、`z-index`を`j`の昇順(後の札ほど手前)にする。32pxは、実測した左上コーナー(ランク+スート表示)の最大幅(ランク「10」で約31px)がちょうど隠れない値。

### 2.3 縦方向の重ね

- `chainOrigin[i] === 'draw'`(山札由来)のカードは`top: 20px`(下がった位置)
- `chainOrigin[i] === 'play'`(場からのプレイ)のカードは`top: 0px`(上がった位置)

20pxは、実測した右下コーナー(ランク+スート表示、`rotate-180`側)を、上の段の札が隠さずに済む最小の高さ(約19px)に少し余裕を持たせた値。

山札ボタンは、この「draw起点(下がった位置、top:20px)」に縦位置を揃える(山札ボタンに`margin-top: 20px`相当のオフセットを付ける)。

### 2.4 1行の表示枚数と折り返し

1行に表示する枚数は13枚固定とする。`wave.chain`(・`chainOrigin`)を13枚ずつのチャンクに分割し、チャンクごとに2.2〜2.3の重ね表示を行う「行」を作る。2つ目以降の行は、1つ目の行の直下に、上下の行のカードが重ならないように配置する。

各行のコンテナの高さは、カード自体の高さ(`aspect-ratio: 2/3`、幅64pxなら96px)+縦方向の重ねオフセット(20px)の合計(116px)にする。この高さぴったりに行を積み重ねることで、ある行の一番下がった札(下端)と次の行の一番上がった札(上端)が重ならないことが保証される。

行が増えるとプレイエリア全体の縦幅がその分広がる(下に伸びる)。山札ボタン・アイテムバッジは1行目の位置のまま、行が増えても動かない。

## 3. データの扱い

`wave.chain`・`wave.chainOrigin`をそのまま使う。行分割は表示側(`+page.svelte`)のみのロジックで、13件ずつの配列チャンクに分割する(`chunk(wave.chain, 13)`のような処理を`{#each}`の外側で行う)。エンジン側のデータ構造・スコア計算には一切影響しない。

## 4. 受け入れ基準

1. プレイエリア下部に、チェーン専用の表示行は存在しない(削除済み)
2. 単独の場札(foundation)表示ボックスは存在せず、チェーンの重ね表示の一番手前の札が現在の場札を表す
3. 山札ボタンの右から、実際のカードと同じサイズのチェーンが、横32px・縦(draw:20px/play:0px)の重ねで表示される
4. 山札ボタンの縦位置が、draw起点のカード(下がった位置)と揃っている
5. チェーンが13枚を超えると、14枚目以降が次の行に折り返して表示される
6. 折り返した行同士が視覚的に重ならない
7. `npm run test`・`npm run build`が成功する
