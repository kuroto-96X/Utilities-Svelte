# 星詠みソリティア -Shidasu- 今後の改善計画

現時点では未着手・未検討のアイデアメモ。着手する際は`superpowers:brainstorming`から設計を詰める。

1. **アイテムなどのモチーフ・名称を決める**
   例: Balatroにおけるタロットカード・JOKER・惑星のカードのような、世界観に沿ったモチーフ体系を検討する。
2. **アイテムなどの詳細な種類と効果の検討**
   2026-07-09、役ボーナス軸のうち「条件が難しい役(階段・列一掃・フラッシュ・ロイヤルセット・コンプリートラン)の緩和」に着手し、既存7個のアイテム(紅の目利き・宮廷の紋章・コンボシールド・厚めの山札・ワイルド★・助走・完全消去)を全て削除、新規に「架橋の護符」(階段緩和)・「寛容の護符」(列一掃緩和)の2個を追加した。あわせて、全アイテムを「1種類につき最大1個まで」保持できるルールに統一した(詳細: `docs/superpowers/specs/2026-07-09-shidasu-item-hard-yaku-relax-design.md`)。
   残タスク: 役ボーナス軸のうち同スート・同色・同ランクの緩和/強化アイテム、コンボ軸・全消し軸・詰み救済軸の新規アイテム、「ワンパン軸」(少ない枚数で高得点)という新軸の検討、ワイルドカードを山札に供給する新規アイテム(現状ワイルドの供給源が無いため、フラッシュ/ロイヤルセット/コンプリートランのワイルド穴埋めルールは実装済みだが未発動)。護符所持上限(5枚)+入れ替えUIは2026-07-13に実装済み(詳細: `docs/superpowers/specs/2026-07-13-shidasu-wildcard-and-item-cap-design.md`)。
3. **デバッグ用の専用画面の検討**
   現在は`DebugPanel.svelte`(開発時のみ表示)で内部状態表示・山札の次を強制指定ができるが、護符の効果検証やステージ/ウェーブの任意設定など、開発時の検証をより効率化するための専用画面(または現行パネルの拡張)を検討する。
4. **ステージ構成の検討**
   現在の3ステージ(none/noLoop/faceLock)構成の見直し・拡張を検討する。
   構想メモ: 1ステージ=10Wave構成にし、10Wave目はボスWave(特定条件でスコアが加算されない等の制限が付く)とする。ボスをクリアするとステージクリアとなり、以降継続するかを選べる。継続した場合はスコアアタック形式になり、以後10Waveごとにボスが出現する(ボスの制限事項はランダムに選ばれる。プレイヤーへの提示タイミングは要検討)。ステージは選択式で、ステージごとに固有の特殊ルールを持つ。ステージをクリアすると新たなステージが選択可能になる。各Waveの目標スコアは、ステージごとに「1Wave目の目標スコア」と「Wave進行ごとの倍率」から算出する。
5. **ゲーム内通貨を定義して、ウェーブ終了ごとにショップでアイテム購入の検討**
   現状、護符はウェーブクリア時の3択提示でのみ入手できる。ゲーム内通貨(仮称)を新設し、ウェーブ終了ごとにショップ画面で護符等を購入できるようにすることを検討する。
6. **画面表示項目の検討**
   スコア・コンボ・チェーンなど、プレイ中に表示する情報項目自体の見直しを検討する。
   護符の並べ替えUI: `docs/shidasu-gofu-candidates.md`の型の凡例で「加算・倍算型の護符が複数ある場合、適用順はプレイヤーの護符の並べ方に依存する(左から順に適用)」と定義したため、所持護符の並び順をプレイヤーが変更できるUI・機能が必要(現状の`+page.svelte`は`[...new Set(run.items)]`で単純な一覧表示のみで、並び替え機能は無い)。
7. **エフェクト・アニメーションの検討**
   得点演出・パターン継続演出・カード移動などのアニメーション強化を検討する。
