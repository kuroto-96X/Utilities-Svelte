# 護符効果 分類一覧(検討用)

Shidasuロードマップ項目2「アイテムなどの詳細な種類と効果の検討」のための、護符(①Talisman)効果案の検討用一覧。バランス調整の議論のたびにこのファイルを更新していく想定。

## 型の凡例

- 加算 … スコアへの加算(取得点後 or 直接点 or ボーナス修飾)
- 倍算 … スコアへの倍算
- 内部干渉 … 取得点の式①の内側(コンボ数・パターン判定等)に作用 ※現行の「護符は取得点の後」定義の外
- ルール … 加点せずゲームルールを変更
- 保護/救済 … コンボ維持・復活系
- 情報 … 表示・可視化のみ
- 資源 … 山札・場札・ワイルド等のリソース操作

レアリティ凡例: C=コモン / U=アンコモン / R=レア
