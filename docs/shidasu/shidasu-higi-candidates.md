# 秘儀効果 候補一覧(検討用)

エルダー・フサルク24ルーンのうち、秘儀(②Rite)として既に実装済みの17種を除いた残り7種(ハガラズ・ナウジズ・イサ・ソウィロ・ベルカナ・エワズ・マンナズ)について、効果の方向性を検討した候補一覧。

本ドキュメントは候補整理のみを目的としており、実装は別途着手する。

## 候補一覧

| ルーン | 効果(確定案) | 持続 | 検討メモ |
|---|---|---|---|
| ハガラズ(Hagalaz) | 場札にある全てのカードを山札に戻し、山札から新たに配り直す | 即時 | - |
| ナウジズ(Nauthiz) | コンボがリセットされる際、`floor((直前のコンボ数-基礎コンボ数)/2)+基礎コンボ数` から再開する(0からではなく) | ウェーブ中ずっと | 祝福(基礎コンボ数を上げる護符)と正しく合成できるよう、基礎コンボ数を除いた分だけ半減させる形にした |
| イサ(Isa) | 発動時点のコンボ数を、そのウェーブが終わるまで増減させず凍結する | ウェーブ中ずっと | 初期案「次の1回の山札引きは山札を減らさない」は弱すぎるとして却下。「山札が減らない」への強化案も検討したが、マンナズ側の効果を変更したことで重複が解消したため、最終的にコンボ凍結案を採用 |
| ソウィロ(Sowilo) | 次に成立した役の種類を記憶し、そのウェーブが終わるまでその役のボーナスを`x`倍にする | ウェーブ中ずっと | - |
| ベルカナ(Berkano) | 発動時点のコンボ数 × `x` を直接点として加算する | 即時 | - |
| マンナズ(Mannaz) | 所持している護符それぞれのレア度に応じた重み(コモン=1、アンコモン=2、レア=4)を合計した値 × `x` を、点数計算時に倍算する。 | ウェーブ中ずっと | 初期案「常に最大到達コンボ数(maxComboThisWave)で計算」は、イサのコンボ凍結案(発動時点で固定・以後増加しない)の完全な上位互換になってしまう(maxComboThisWaveは常にコンボ凍結の値以上で、かつ以後の伸びも取り込める)ため却下。所持護符のレア度という別軸に変更した |
| エワズ(Ehwaz) | そのウェーブが終わるまで、場札の許容ランク差を2差まで拡張する(ループを跨ぐK→2、Q→Aなども対象)。階段パターンの継続条件も、昇順/降順の方向が一定である限り、1差・2差が混在してもよいように緩和する | ウェーブ中ずっと | 初期案(場札全体の入れ替え・山札との交換系)は「弱い」「もっと強力に」と複数回の却下を経て、最終的にランク差ルール自体の緩和案に変更された |

## 実装時の留意点(参考メモ)

- エワズは`isPlayable`の隣接判定(現行はランク差`d===1`、ループ時`d===12`)と、階段パターン判定(`analyzeStair`/`stepRank`、現行はステップ幅1固定)の両方に手を入れる必要がある。この2つは循環・輪廻・威光などの護符や`noLoop`ステージ修飾子からも参照される中核ロジックのため、実装時は影響範囲の確認が必要
- 上記7案は候補整理のみであり、実装は本ドキュメントの範囲外(別途着手する)
