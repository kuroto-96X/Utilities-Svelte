# 秘儀効果 候補一覧(検討用)

エルダー・フサルク24ルーンのうち、秘儀(②Rite)として既に実装済みの17種を除いた残り7種(ハガラズ・ナウジズ・イサ・ソウィロ・ベルカナ・エワズ・マンナズ)について、効果の方向性を検討した候補一覧。

本ドキュメントは候補整理のみを目的としており、実装は別途着手する。

## 候補一覧

| ルーン | 効果(確定案) | 持続 | 検討メモ |
|---|---|---|---|
| ハガラズ(Hagalaz) | 場札にある全てのカードを山札に戻し、山札から新たに配り直す | 即時 | - |
| ナウジズ(Nauthiz) | コンボがリセットされる際、`floor((直前のコンボ数-基礎コンボ数)/2)+基礎コンボ数` から再開する(0からではなく) | ウェーブ中ずっと | 祝福(基礎コンボ数を上げる護符)と正しく合成できるよう、基礎コンボ数を除いた分だけ半減させる形にした |
| イサ(Isa) | 発動時点のコンボ数を、そのウェーブが終わるまで増減させず凍結する | ウェーブ中ずっと | 初期案「次の1回の山札引きは山札を減らさない」は弱すぎるとして却下。「山札が減らない」への強化案も検討したが、マンナズ側の効果を変更したことで重複が解消したため、最終的にコンボ凍結案を採用 |
| ソウィロ(Sowilo) | 次に成立した役の種類を記憶し、そのウェーブが終わるまでその役のボーナスを`x`倍にする | ウェーブ中ずっと | - |
| ベルカナ(Berkano) | 現在のコンボ数を`x`倍にする(端数切り捨て) | 即時 | 当初案「発動時点のコンボ数×xを直接点として加算」から、既存のuruz(コンボ+n)と同じ設計に揃えるため「コンボ数自体を×x倍にする」に変更した |
| マンナズ(Mannaz) | 所持している護符それぞれのレア度に応じた重み(コモン=1、アンコモン=2、レア=4)を合計した値 × `x` を1に加えた係数を、得点計算時に倍算する | ウェーブ中ずっと | 初期案「常に最大到達コンボ数(maxComboThisWave)で計算」は、イサのコンボ凍結案の完全な上位互換になってしまうため却下。所持護符のレア度という別軸に変更した。当初案「役成立ごとに加算」から、既存の護符(琥珀・蒼穹)と同じ「1+値×x」の乗算パターンに揃えるため変更した |
| エワズ(Ehwaz) | そのウェーブが終わるまで、場札の許容ランク差を2差まで拡張する(ループを跨ぐK→2、Q→Aなども対象)。階段判定には影響しない(ランク差2のプレイは階段を継続させない) | ウェーブ中ずっと | 初期案(場札全体の入れ替え・山札との交換系)は「弱い」「もっと強力に」と複数回の却下を経て、最終的にランク差ルール自体の緩和案に変更された。当初は階段判定も緩和する案だったが、実装設計時にワイルド絡みの複雑さを避けるため階段判定には手を入れない方針に変更した |
