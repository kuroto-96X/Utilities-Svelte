# レリックの追加 検討用メモ(現状整理)

Shidasuロードマップ項目2「レリックの追加の検討」の現状を整理するワークシート。

## レリックの説明

レリックは、ショップ販売価格の減少・ショップ商品提示数の増加・リロールコストの減少・秘儀/天啓/神託の所持上限増加など、ランを通して効果があり、護符の守備範囲外(ゲームプレイに直接かかわる部分以外)で有利になる効果を持つアイテム。

- 所持数に上限は無いが、同じレリックを重複所持することはできない(1種類につき最大1個)
- 売却は不可
- 個体ごとに「付喪化」(進化)状態を持ち、付喪化すると効果が上方修正される(付喪化の手段は天啓「虚」)
- ショップ専用枠(基本1枠、レリック「縁起鈴」所持時は複数枠)で単品購入する。バラ売り枠・福袋枠とは別枠
- システムの仕組み自体は`docs/superpowers/specs/2026-08-12-shidasu-relic-system-design.md`で設計・実装済み

## 今後の検討課題

### 候補1: オファー拡張(仮称)

天啓候補審査(完了済み、`docs/shidasu/done/shidasu-revelation-candidates.md`の候補24)で「天啓ではなくレリック向き」として不採用となった効果。「次回ショップのオファー数を一時的に増やす」という内容で、天啓としては他の即時効果系(Phase B)と性質が異なるため見送られた経緯がある。レリックの効果候補として転用できる可能性があるが、既存の「縁起小槌」(福袋の選択肢数を増やす)・「熊手」「福笹」(バラ売り/福袋の枠数を増やす)と効果の性質が近く、差別化(一時的 vs 恒常的、等)の検討が必要。詳細な効果内容・変数は未検討。

### 候補2: 独楽(こま、仮称、保留中)

`docs/shidasu/done/shidasu-relic-candidates.md`の第1弾検討時に候補に挙がったが、以下の理由で保留となっていたレリック候補。

- 効果案: Wave開始時、場札に配る行数を`n`増やす(`extraTableauRows`の仕組みを使う)
- 保留理由: 検討当時、既存の護符「暗雲」・天啓「虚」が同じ`extraTableauRows`の仕組みを使っており機能重複していたため保留
- **2026-08-13、護符「暗雲」・天啓「虚」は削除済み**(`extraTableauRows`のみを効果とする単機能アイテムだったため、新規効果の割り当てを行わず単純削除。詳細は`docs/shidasu/shidasu-roadmap.md`の「完了済み(履歴)」内「護符「暗雲」・天啓「虚」の削除」を参照)。これにより機能重複が解消され、独楽のレリック化検討が再開可能な状態になっている
- **未着手**: 具体的な効果内容(`n`の初期値、付喪化時の強化内容)・レリック名は仮称のまま確定していない

### 候補3: セット効果系レリック(仮称、モチーフ検討中)

「単体では効果が無く(または非常に小さく)、複数集めることで初めて強い効果を発揮する」という新しいタイプのレリック。既存10種はいずれも1個から即座に効果を発揮する設計のため、これは新しい性質のレリック群になる。日本の縁起物・置物・郷土玩具というレリックのモチーフの雰囲気に沿う候補として、以下を洗い出した(効果内容・必要個数・数値は未検討、モチーフの方向性のみ)。

| モチーフ候補 | 由来・雰囲気 |
|---|---|
| 七福神 | 7柱揃って初めて完全な功徳(七難即滅七福即生)があるとされる信仰。「単体無効・複数で強力」に最も直接的に合致する。既存レリックと同じ縁起物モチーフの中心的存在でもある |
| 勾玉(まがたま) | 三種の神器の一つ。単体では意味が薄いが、連ねて首飾りにすることで力を持つという伝承があり、「集めるほど強くなる」世界観と相性が良い |
| 宝船 | 七福神が乗るとされる船。七福神モチーフの発展形として、七福神そのものではなく「船に乗せる」という集合の器として扱う案 |
| 鯉のぼり | 家族の数だけ吊るす文化があり、複数まとめて意味を成す点で相性がある。ただし縁起物としての「収集」性は七福神ほど強くない |
| 結び守り(お守り) | 神社で複数体集める文化もあるが、他候補に比べるとモチーフとしての訴求力はやや弱い |

**未着手**: どのモチーフを採用するか・具体的な効果内容(何を何個集めるとどうなるか、既存10種のどの系統[価格/枠数/上限]と組み合わせるか)は未検討。
