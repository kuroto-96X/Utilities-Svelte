# 護符効果 分類一覧(検討用)

Shidasuロードマップ項目2「アイテムなどの詳細な種類と効果の検討」のための、護符(①Talisman)効果案の検討用一覧。バランス調整の議論のたびにこのファイルを更新していく想定。

## 型の凡例

護符の効果は、特に説明が無い場合は「場札からプレイした時の点数計算」に加算または倍算される。点数計算は以下の順序で行われる:

1. 取得点 = (プレイの基礎点 + 基礎点加算) × コンボ数による倍率 で算出する(`shidasu-current-rules.md`4.1〜4.3節の`gained = floor(base × multiplier)`に相当。基礎点加算=チェーンボーナス・列一掃ボーナス)
2. 上記1で算出した取得点に対して、加算・倍算型の護符の効果を実行する
3. 加算・倍算型の護符が複数ある場合、適用順はプレイヤーの護符の並べ方に依存する(左から順に適用)

- 加算 … 上記1で算出した取得点に対する加算(特に説明が無い場合)
- 倍算 … 上記1で算出した取得点に対する倍算(特に説明が無い場合)
- 内部干渉 … 上記1の式そのものの内側(コンボ数・パターン判定等)に作用するもの。式の外側(算出済みの取得点)ではなく、式の内部パラメータを書き換える
- ルール … 加点せずゲームルールを変更
- 保護/救済 … コンボ維持・復活系
- 情報 … 表示・可視化のみ
- 資源 … 山札・場札・ワイルド等のリソース操作

加点先が「直接点」の護符・効果は、上記の点数計算(取得点)とは無関係に、即座にスコアへ反映される(全消しボーナスと同様、コンボ倍率の影響を受けない)。

レアリティ凡例: C=コモン / U=アンコモン / R=レア

## 要対応メモ

- ~~永劫と豊穣が同一効果~~ → **解消**: 豊穣は「場札のうち1枚をランダムにワイルドへ変換」に変更し、永劫(山札にワイルドを新規追加)と対象を分離した
- ~~「武器」の名前重複~~ → **解決済み**: 旧「武器」(♠のみでコンボ中x倍算)を「真剣」に改名し、新規候補の「武器」(♠の枚数*n点加算)をそのまま「武器」として確定
- ~~「寛容」の名前重複(実装との衝突)~~ → **対応方針決定**: Shidasu本体に実装済みの「寛容の護符」(列一掃ボーナスの条件緩和、詳細は`docs/superpowers/specs/2026-07-09-shidasu-item-hard-yaku-relax-design.md`)の効果を、本リストの「寛容」(列一掃の必要枚数を-m枚)に差し替える予定。実装作業は別途着手する
- ~~未定義用語: 役 / 同ランク役 / フラッシュ / 列一掃~~ → **定義済み**: `docs/shidasu-current-rules.md`4.2節に「パターンボーナス」(同スート・同色・★同スート・階段)と「役ボーナス」(場札を取った時の点数計算に適用されるボーナスのうちパターン以外の全て。フラッシュ・ロイヤルセット・同ランク・コンプリートラン・列一掃)の分類を定義した。「同ランク役」は「役」の一種として整理済み。「列一掃」は役ボーナスの一種として同ドキュメント4.3節に位置づけ済み
- ~~未定義用語: 全ランク~~ → **定義済み**: 輪廻・威光の「全ランク(階段)」は、コンプリートラン(チェーン内で13ランク全てが出揃うこと)と同じ概念を指す。ただしこの2枚は追加で「階段の形になっている」ことも要求している点でコンプリートラン単体より厳しい条件
- ~~未定義用語: 基礎コンボ数~~ → **定義済み**(祝福で使用): コンボがリセットされた時に採用される、コンボ数の初期値。既定では常に0(=通常のコンボリセットは必ずコンボ0から再開する)。基礎コンボ数自体をmだけ加算する効果を持たせると、以後コンボがリセットされるたびにコンボ数は0ではなくmから再開するようになる。また、コンボ継続中に基礎コンボ数がmだけ加算された場合は、現在のコンボ数にも同時に+mされるが、これは直前にプレイしたカードの点数計算には反映されず、次にカードを取る/引く際の点数計算(コンボ倍率の算出)から反映される
- ~~「全ランク緩和」(謙虚)~~ → **解消**: 「全ランク緩和」は効果設定の方向性を示すメモに過ぎなかった。謙虚の効果は「コンプリートランの必要枚数を-m枚」に確定(寛容と同型のルール変更)
- 刻限は加点先/タイミングの明記が必要
- ~~実装済み「架橋の護符」の記載漏れ~~ → **解消**: 一覧に無かったため、情報型で役割が薄かった予兆(C)と入れ替える形で追加。あわせて高潔(旧:効果未確定)を「同スートパターンでn点加算」、誠実(旧:加点先未確定)を「同色パターンでのコンボ継続時に直接点n点」として効果を確定(高潔=同スート/誠実=同色の対構造)
- 表内の変数命名規則: 「枚数」(カード枚数)に関する変数は`m`、「コンボ数」に関する変数(閾値・加算値とも)は`c`、「行数」に関する変数は`r`、それ以外(点数・倍率・確率)は`n`/`x`/`p`を用いる
