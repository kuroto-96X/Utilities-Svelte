# 秘儀の将来的な再編候補メモ(検討用)

`shidasu-revelation-candidates.md`の天啓候補24個の採用可否を検討する過程(2026-08-09)で決まった方針の記録。本ドキュメントは実装対象の選定・実装自体を目的とせず、将来「秘儀の追加の検討」(ロードマップ項目2)に着手する際の材料を残すためのメモ。

## 方針

- **天啓 = カード変換系(スート・ランク・ワイルド変換)、秘儀 = それ以外**、という役割分担を今後の設計方針とする
- 現在実装済みの秘儀24種(エルダー・フサルク全24種)のうち、カードを変換する効果を持つものは、将来的に天啓側の候補として再設計する
- 今後、秘儀に新しい効果を追加する際は、カード変換系ではなく別の軸(コンボ操作・フラグ系・カード移動・リソース獲得など、既存の大多数の秘儀と同じ傾向)を優先する
- 秘儀のモチーフ(北欧ルーン24種)は、2026-08-11にBの9種を削除したことで9枠(ᚱ・ᚹ・ᛟ・ᛈ・ᛏ・ᛚ・ᚨ・ᚲ・ᚦ)が空いている。将来秘儀を追加する際はこの空き枠に割り当てられるため、モチーフ自体の拡張は不要になった

## A. 天啓候補審査で不採用となった候補(秘儀候補への転用素材、10個)

`shidasu-revelation-candidates.md`の24候補のうち不採用と判断された候補。天啓の趣旨(カード変換・場札構成操作)からは外れる/技術的コストが高いと判断されたものだが、内容自体は秘儀(カード変換以外の効果)の候補として再利用できる。

| 名前(仮) | 元の効果 | 不採用理由(天啓候補として) |
|---|---|---|
| 列ランク統一変換 | 選んだ1列を特定ランクに統一する | 単純だが天啓のランク変換候補としては優先度低 |
| 絵札/数字札交換 | 選んだ1列の絵札↔数字札をランダム変換 | 既存牛(gyu)・女(jo)と役割が近い |
| 山札積み直し | 選んだ1列を丸ごと山札の一番上に積み直す | `tableau`→`stock`移動の新規実装が必要 |
| 同ランク統一 | デッキ全体から特定ランクを選び同一スートに揃える | デッキ全体を対象にする点が既存候補と乖離 |
| 列入れ替え | 場札の2列を選び中身をまるごと入れ替える | 実装は容易だが天啓としての採用見送り |
| 列逆順 | 選んだ1列のカードの並び順を上下逆にする | 実装は容易だが天啓としての採用見送り |
| 場札列数拡張 | 場札の列数自体を恒久的に1列増やす | レイアウトUI・列選択ロジックへの影響が大きい |
| チェーン保持配り直し | コンボを保持したまま場札を丸ごと配り直す | コンボ保持のまま再配布する前例がなく実装コスト高 |
| 犠牲シャッフル増量 | 選んだ1列を山札へ戻す代わりに山札枚数を増やす | デメリット付き効果で天啓の趣旨と合わない |
| 目標軽減 | ウェーブの目標スコアを一時的に引き下げる | 場札・デッキ構成と無関係で天啓の趣旨から外れる |

(候補24「オファー拡張」は不採用としたが、秘儀候補ではなくロードマップ項目6「レリックの実装」の候補として別途扱う)

## B. 既存秘儀のうちカード変換系(天啓候補への転用素材、9個)

現在実装済みの秘儀24種のうち、スート・ランク・ワイルドへの変換を伴うもの9個は、`shidasu-revelation-candidates.md`の天啓候補として1つずつ採用可否を検討することにしたため、同ドキュメントに転記した(2026-08-09)。検討の結果、9個中3個が天啓として採用・実装され、6個は不採用となった(詳細は`docs/shidasu/done/shidasu-revelation-candidates.md`を参照)。

### 結果(2026-08-11、秘儀の実装から削除完了)

Bの9個は、秘儀の実装(`RiteId`型・`RITE_POOL`・`riteEffects.ts`・`params.ts`・`shidasu.config.json`ほか)からすべて削除した。秘儀の所持プール(`RITE_POOL`)は24種→15種に減少した。

| 秘儀(旧グリフ) | 旧RiteId | 天啓への転用状況 |
|---|---|---|
| ライドー(ᚱ) | raidho | 畢(hitsu)として天啓側にのみ現存 |
| ペルスロ(ᛈ) | perthro | 觜(shi)として天啓側にのみ現存 |
| アンスズ(ᚨ) | ansuz | 井(sei)として天啓側にのみ現存 |
| ウンヨー(ᚹ) | wunjo | 完全削除(天啓にも存在しない) |
| オセラ(ᛟ) | othala | 完全削除(天啓にも存在しない) |
| ティワズ(ᛏ) | tiwaz | 完全削除(天啓にも存在しない) |
| ラグズ(ᛚ) | laguz | 完全削除(天啓にも存在しない) |

| スリサズ(ᚦ) | thurisaz | 完全削除(天啓にも存在しない) |

空いた9つのグリフは、将来秘儀を追加する際にモチーフ拡張なしでそのまま再利用できる。完全削除された6個(天啓側にも存在しないもの)の効果内容は、将来の秘儀追加時の材料として以下に残す。

| 旧RiteId | 効果 |
|---|---|
| wunjo | 場札全体の非ワイルドカードを赤黒の多い方の色へランダムなスートで統一変換する |
| othala | 場札全体の非ワイルドカードを最多スートへ統一変換する |
| tiwaz | チェーン全体(非ワイルド)を最多スートへ統一変換する(チェーンが2枚以上のときのみ使用可) |
| laguz | チェーン全体(非ワイルド)を赤黒の多い方の色へランダムなスートで統一変換する(チェーンが2枚以上のときのみ使用可) |

| thurisaz | 場札の非ワイルド・絵札をランダムに1〜10へ変換する(スート維持) |
