# 報酬増加系護符 候補一覧(検討用)

Shidasuロードマップ項目1「『報酬増加系の護符』の追加を検討する」のための、名前候補・効果の方向性・個別効果をまとめて検討するワークシート。「報酬増加系」は星片(ゲーム内通貨)を直接増やす方向の護符を指す。

このドキュメントは複数セッションにまたがって育てていく想定。名前候補(80個)・方向性(3個)は決定済み(2026-08-22)。個別の効果(どの名前にどの方向性のどんな効果を割り当てるか)は未着手で、以降のセッションで随時この下の「個別効果の検討」セクションに追記していく。

## 制約

- 全て**二文字の漢字のみ**で構成する(ひらがな・カタカナ・3文字以上は対象外)
- 既存の護符名99個(`src/lib/game/shidasu/shidasu.config.json`の`talismans`)と重複しない
- 金運・商売・繁盛・実り・利益・報酬・縁起・栄達をテーマとし、既存99個の傾向(自然現象・美徳・宝石・運命系の語彙が中心)とは異なる方向性で選定した
- 「福袋」はショップの既存パック(福袋、`packKind`)の名称と意味が衝突するため候補から除外した
- 「実り」「埋蔵金」「大入り」は二文字漢字の制約(ひらがな混じり・3文字)を満たさないため候補から除外した

## 効果の方向性(3個)

検討の出発点として5つの方向性案があったが、うち2つは既存のレリック(招き猫・開運こけし・数珠・千社札・算盤)が既にカバーしている領域と重複するため、検討対象から除外した(2026-08-22判断)。

- **除外1: 護符・秘儀・神託・天啓の売値の操作** — レリック「招き猫」(購入価格割引)・「開運こけし」(売却価格増加)が既に全アイテム一律の売買価格操作を担っている。
- **除外2: Waveクリア時に追加報酬(星片の利息や所持アイテムの数や売値に応じた報酬など)** — レリック「数珠」(利息系)・「千社札」(所持数ボーナス)・「算盤」(売値ボーナス)が既にWaveクリア時の追加報酬を担っている。

レリックは少数精選で無条件・大規模な一律効果、護符は多数の中から個別の小さな効果を組み合わせる設計という位置づけの違いがあり、両者が同じテーマ(報酬)を扱うこと自体は問題ないが、上記2件は既存レリックと効果の中身が直接重複するため除外した。

残った3方向性を検討対象として確定した:

1. **特定行動で自分自身の売値を増加**: 護符自身の売却価格を、プレイ中の特定の行動・条件によって一時的または永続的に上昇させる。護符本体の価値を操作する方向性。
2. **プレイ中に特定条件を満たした場合に即時報酬**: カードプレイ中、特定の役が成立した・特定のスートやランクがチェーンに含まれている等の条件を満たした瞬間に、星片を即座に獲得する。既存の「得点内訳(gained/clearBonus)」パイプラインとは別の、通貨(`currency`)への直接加算という新しい経路になる。
3. **秘儀・天啓・神託使用時にキャッシュバック**: 秘儀・天啓・神託を使用(消費)した際、使用したこと自体をトリガーとして星片を獲得する。アイテム運用(使う・貯める)という行動そのものに報酬を結びつける方向性。
