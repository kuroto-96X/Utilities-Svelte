# 星詠みソリティア -Shidasu- 用語集

`src/lib/game/shidasu/{engine,types,params,deck}.ts` の実装・コメントを元にした、Shidasuで使われる用語の定義集。ルールの詳しい計算式・数値は `docs/shidasu-current-rules.md`(現行仕様書)を参照。本ドキュメントは「何と呼ぶか」「何を指すか」の整理に特化する。

各項目は「**日本語用語**(コード上の識別子) — 定義」の形式で記載する。コード上の識別子が存在しない(UI表示専用・概念のみの)用語は識別子欄を省略する。

## 1. 進行構造

- **ラン**(`RunState`, 1周) — タイトルからスタートし、3ステージ×各3ウェーブ=計9ウェーブを順にクリアしていく一連のプレイ全体。全ウェーブクリアで「全ステージクリア」となる。
- **ステージ**(`stages[]`, `stageIndex`) — ラン内に3つ存在する区切り。各ステージは固有の**ステージ制約**(`modifier`)と、ウェーブごとの**目標スコア**(`targets`)を持つ。
- **ウェーブ**(`WaveState`, `waveIndex`) — 山を1組配り直してから、目標スコア到達・全消し・手詰まりのいずれかで終了するまでの1回のプレイ単位。1ステージにつき3ウェーブ存在する。
- **フェーズ**(`RunPhase`) — ラン全体の現在の状態。`title`(タイトル画面)→`playing`(プレイ中)→`itemSelect`(護符選択)/`stageClear`(ステージクリア演出)/`allClear`(全クリア)/`gameOver`(目標未達)を遷移する。
- **ステージ制約**(`StageModifier`) — ステージごとに適用される特別ルール。`none`(制約なし)・`noLoop`(A⇔Kループ禁止)・`faceLock`(絵札はコンボ2以上でのみ取得可)の3種類。

## 2. 盤面要素

- **場札**(`tableau: Card[][]`) — 列ごとに積まれた、まだ取っていないカードの山。列数×段数(既定7列×5段)で初期配布される。各列の一番手前(配列の末尾)のカードだけが取得対象になる。
- **山札**(`stock: Card[]`) — 場札配布後に残る、めくって使う予備の札。
- **基準カード**(`foundation`) — 場札から取得可能かどうかを判定する際の比較対象になる、直前に取得/めくったカード。取得したカードが新しい基準カードになる。
- **チェーン**(`chain: Card[]`) — 現在のコンボで取得/めくった順に並んだカードの履歴。コンボがリセットされると空になる(直後の1枚から再スタート)。
- **コンボ**(`combo`) — チェーンが途切れずに続いている回数。カードを取得/パターン継続でめくるたびに+1され(黄金の護符所持時は+2)、条件を満たさずめくった場合や手詰まりで0にリセットされる。
- **チェーン内での計算用コンボ**(`effectiveCombo`) — スコア計算のその場限りで使う一時的なコンボ値。庇護・大地・祝福などの護符がこの値だけを底上げ/加算し、実際に保存される`wave.combo`自体は変化しない。
- **捨て札**(`discardPile: Card[]`) — コンボリセット時にチェーンにあったカードが送られる、ウェーブ限定の一時置き場。不屈・再生の護符が復活時にここから場札へ戻す。ウェーブをまたいで持続しない。
- **デッキ構成**(`DeckCard[]`, `deckComposition`) — ラン全体で持続する、山札の中身(スート・ランク・ワイルド判定)の構成。永劫・豊穣・静寂の護符によって書き換えられ、以後のウェーブにも引き継がれる。
- **ワイルド**(`wild: boolean`) — その時点で必要とされるランク・スートの代役として振る舞うカード。判定ごとに都合の良いランク・スートとして独立に解釈される(詳細: `docs/shidasu-current-rules.md` 4.7〜4.8節)。

## 3. スコアリング

- **獲得点**(`gained`, `lastGain: ScoreGain`) — 1回のプレイ/めくりで実際に加算される点数。`基礎点 = 100 + チェーンボーナス合計 + 列一掃ボーナス`に**コンボ倍率**を掛けた値が土台になる。
- **コンボ倍率**(`multiplier`) — `1 + (コンボ数 - 1) × comboMultiplierStep(既定0.1)`。コンボが伸びるほど際限なく上昇する。
- **パターンボーナス** — チェーン全体が共通の条件(同スート・同色・階段)を保ち続けている間、条件を満たすたびに毎回加点されるボーナス。条件が一度でも崩れると、そのコンボがリセットされるまで二度と成立しない。山札めくりでの「パターン継続」判定もこの3条件のみを対象にする。
- **役ボーナス** — パターンボーナス以外の全ての加点条件の総称。直近数枚の窓(フラッシュ・ロイヤルセット)、チェーン内の出現回数(同ランク)、到達種類数(コンプリートラン)、列の状態(列一掃)など、チェーン全体の連続性に依存しない条件で判定される。途中でスート・色・階段が崩れていても独立して成立しうる。
- **役**(`RoleName`) — 役ボーナスの種類名。`flush`(フラッシュ)・`royalSet`(ロイヤルセット)・`sameRank`(同ランク)・`completeRun`(コンプリートラン)・`columnSweep`(列一掃)の5種類。
- **列一掃** — 場札の1列を最後の1枚まで取り、その列が空になった時に成立する役ボーナス。「連続コンボが始まった時点でその列が(ほぼ)全段残っていたか」が条件になる。
- **全消し**(`endReason: 'fullClear'`) — 場札が0枚になった瞬間にウェーブが終了する状態。コンボ倍率を通さず、加点式の外側で全消しボーナスが加算される。
- **目標達成**(`endReason: 'target'`) — プレイ後のスコアがそのウェーブの目標スコア以上になった瞬間にウェーブが終了する状態。
- **手詰まり**(`endReason: 'stuck'`, `isStuck`) — 場札が1枚以上残っているのに山札が0枚で、かつ取得可能な列が1つもない状態。操作後600msの無操作を検知して判定される。

## 4. 護符(アイテム)システム

- **護符**(`ItemId`, `talismans`) — ウェーブクリア時に選択して以後常時発動するパッシブ効果。現状実装されている唯一のアイテム分類(将来構想の秘儀・天啓・神託は未実装、`docs/shidasu-roadmap.md`参照)。全87種類。
- **護符オファー**(`offer: ItemId[]`, `rollItemOffer`) — ウェーブクリア時(ステージ内最終ウェーブを除く)に未所持の護符から最大3個ランダムに提示される選択肢。
- **所持上限**(`items.maxItems`, 既定5) — 護符を同時に保持できる最大枚数。上限到達時に新しい護符を選ぶと、既存の護符と入れ替えるステップに切り替わる(`confirmItemSwap`)。
- **所持順解決** — 加算・倍算型の護符が複数所持されている場合、効果の適用順は取得した順(`items`配列の並び順)に固定されるという大原則。並べ替えUIは未実装(`docs/shidasu-roadmap.md`項目6)。
- **護符名**(`talismans[id].name`) — 護符の表示名。従来はコード内`ITEM_NAMES`にハードコードされていたが、`/admin/shidasu-talismans`で編集可能な`talismans[id].name`パラメータに統合された。
- **効果説明文**(`itemDesc(id, params)`) — 護符の効果を、現在のパラメータ値を埋め込んで動的に生成する説明文。ゲーム内のアイテム選択画面や管理画面のプレビューに表示される。

## 5. 内部実装の分類用語

- **gainedチャンネル / clearBonusチャンネル**(`ITEM_EFFECTS`, `ItemEffect`) — 護符の加算・倍算効果が、獲得点(`gained`)と全消しボーナス(`clearBonus`)のどちらに作用するかを表す区分。`applyItemEffects`が`items`配列の並び順(所持順)に効果を適用する。
- **直接加算(Directエフェクト)**(`DirectEffectContext`, `applyDirectEffects`) — コンボ倍率を通さず、スコアに直接加算される護符効果の総称。発生タイミングごとに4種類のチャンネルに分かれる: `resetDirect`(コンボリセット時)・`stockEmptyDirect`(山札が尽きた時)・`comboMilestoneDirect`(コンボが一定数に到達した瞬間)・`drawContinueDirect`(山札めくりでパターン継続した時)。

## 6. デバッグ・管理画面

- **デバッグサンドボックス**(`/admin/shidasu-debug`) — 実プレイセッションとは独立に、護符の付与/削除や場札・山札のカード入れ替えをその場で試せる検証用画面。
- **護符パラメータ設定ページ**(`/admin/shidasu-talismans`) — 87護符の名前・数値パラメータ・効果説明文プレビューを1護符1行のテーブルで編集する管理画面。
