# 報酬増加系護符 名前候補一覧(検討用)

Shidasuロードマップ項目1「『報酬増加系の護符』の追加を検討する」のための、名前候補一覧。「報酬増加系」は星片(ゲーム内通貨)報酬の増加・護符売値の上昇など、得点そのものではなく手持ちの星片を増やす方向の護符を指す。

本ドキュメントは名前候補の洗い出しのみが目的で、各名前に対応する具体的な効果の検討・実装対象の選定は別セッションで行う。

## 制約

- 全て**二文字の漢字のみ**で構成する(ひらがな・カタカナ・3文字以上は対象外)
- 既存の護符名99個(`src/lib/game/shidasu/shidasu.config.json`の`talismans`)と重複しない
- 金運・商売・繁盛・実り・利益・報酬・縁起・栄達をテーマとし、既存99個の傾向(自然現象・美徳・宝石・運命系の語彙が中心)とは異なる方向性で選定した
- 「福袋」はショップの既存パック(福袋、`packKind`)の名称と意味が衝突するため候補から除外した
- 「実り」「埋蔵金」「大入り」は二文字漢字の制約(ひらがな混じり・3文字)を満たさないため候補から除外した

## 除外・非対象

- 各名前に対応する具体的な護符効果(星片報酬を何%増やすか、売値をどう上げるか等)の検討は本ドキュメントの対象外
- 「ワンパン軸の護符」(ロードマップ項目1のもう一つの検討事項)の名前候補は本ドキュメントの対象外。別途検討する
- 実装時に選定した名前が80個の中に無い場合、本ドキュメントの制約(二文字漢字・既存99個との非重複)を満たす範囲で追加候補を検討する
